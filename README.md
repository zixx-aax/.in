## 🌟 Overview

**MK HTML Cloud Studio** is a state-of-the-art, high-performance, browser-based cloud IDE and instant deployment suite designed by **MK_BOTS™**. It empowers developers, creators, and hobbyists to write, debug, preview, and host standalone **HTML, CSS, and JavaScript** applications directly in the cloud with real-time syntax intelligence, custom link naming, creator-locked editing security, local link history tracking, and unlimited project scaling.

## 🚀 Core Features

- 🌌 **Immersive VFX Landing Page:** Built with custom interactive particle mesh canvas physics, glassmorphism UI, and dynamic status counters.
- 💻 **Real HTML/CSS/JS IDE & Starter Templates:** Powered by CodeMirror (`material-ocean` theme) with line numbers, active-line glow, auto-formatting, and instant templates (*Basic HTML5, Tailwind CSS, Interactive Canvas Game*).
- ⛶ **True Full-Screen Coding Mode:** Distraction-free native full-screen workspace featuring quick snippet chips (`<div>`, `<style>`, `<script>`, `Flex Box`), font scaling (`A+`/`A-`), code formatting, and side-by-side **🌓 Split Live Preview**.
- 📱 **Responsive Full-Screen Preview Suite:** Switch effortlessly between **💻 Desktop** and **📱 Mobile (375×680)** viewports.
- 🔗 **Named Permanent & Temporary Cloud Links:** Generate time-bound links (in minutes) or permanent password-protected cloud endpoints (`L`) with optional custom link names.
- 🔐 **Creator-Locked Live Link Editing:** Push real-time code updates to existing permanent URLs without changing the link—protected so User B can never overwrite User A's link.
- 🗂️ **Dual Local Storage History:** Tracks both your **📁 Saved Local Files** and your **🔗 Created Links History** (complete with timestamps, `PERM`/`TEMP` badges, and full source code recovery).
- 💎 **Branded Watermark Footer:** Automatically embeds the official **MK_BOTS™** branding and rights notice across all studio previews and deployed cloud viewers.

## 🛠️ How It Works

```mermaid
graph LR
    A["🚀 Launch Studio"] --> B["💻 Code in True Full-Screen IDE"]
    B --> C["🌓 Test in Live, Split or Mobile Preview"]
    C --> D["🏷️ Name Link and Lock with Creator Token"]
    D --> E["🔗 Deploy Cloud Link and Save to History"]
```

1. **Launch Studio:** Open the live web application and click **🚀 Launch Studio Workspace** from the animated landing page.
2. **Code with Pro Tools:** Write your code with real-time `<tag>` autocomplete, red-line error detection, or enter **⛶ Full Screen Editor** for a 100% native full-screen coding experience.
3. **Test & Inspect:** Click **▶ Run Preview**, toggle **🌓 Split Live Preview**, or open the **🔍 Full Screen Preview Suite** to test mobile and desktop responsiveness.
4. **Deploy & Manage History:** Click **🚀 Generate Link**, choose temporary minutes or type `permanent` (with master password `L`), optionally name your link, and access your link or reload its code anytime from the **🔗 Created Links History** panel!
